🔎 TextLens AI — Generative AI Text Analysis

📌 Project Overview

TextLens AI is a Generative AI project that analyses writing patterns using the Gemini API. It provides qualitative insights into writing style, sentence structure, repetition, and patterns that may occur in AI-assisted or human writing.

🎯 Objectives

- Explore writing patterns using Generative AI.
- Analyse sentence structure and repetition.
- Generate easy-to-understand writing insights.
- Export analysis results as a downloadable text report.

✨ Features

- Interactive web interface built with Streamlit.
- AI-assisted writing-style analysis using the Gemini API.
- Word and character counters.
- Downloadable analysis report.
- Secure password-style API key input.
- Clear disclaimer about the limitations of authorship detection.

🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI SDK

⚙️ Installation and Setup

1. Clone this repository:
   
   "git clone https://github.com/YOUR_USERNAME/textlens-ai.git"

2. Open the project folder:
   
   "cd textlens-ai"

3. Install the required libraries:
   
   "pip install -r requirements.txt"

4. Start the application:
   
   "streamlit run app.py"

5. Open the local URL displayed in your terminal.

6. Enter your Gemini API key in the application and submit text for analysis.

📄 Output

The application displays writing-style analysis and allows users to download a text report containing the analysed text and generated insights.

⚠️ Limitations

TextLens AI is an educational project, not a validated AI-authorship detector. Writing style alone cannot reliably establish whether a text was written by a human or an AI system. Its assessments should be treated as exploratory rather than definitive.
